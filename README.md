# watermark-removal

An [Agent Skill](https://skills.sh) for removing or adding watermarks on images and video with `ffmpeg` and `ImageMagick`.

```
npx skills add <your-github-user>/watermark-removal
```

## What it does

- **Images** — crop, patch, add text/logo watermarks
- **Video** — `delogo`, blur, crop, `drawtext`, `overlay`
- **Batch** — process whole folders
- **Ethics** — only for content you have rights to

See [`SKILL.md`](./SKILL.md) for the full instructions.
